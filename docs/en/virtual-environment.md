## Python Virtual Environment

Create

```bash
python3 -m venv .venv
```

Activate (Ubuntu)

```bash
source .venv/bin/activate
```

Deactivate when finished

```bash
deactivate
```

The virtual environment directory (`.venv/`) is excluded from Git via `.gitignore`.
